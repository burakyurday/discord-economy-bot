# BPTBS

Discord economy and sales bot project built with JavaScript and discord.js v14.

> **Status:** Legacy project / reference implementation. Dependencies and runtime have not been verified against current Discord APIs.

## Overview

The repository contains a slash-command Discord bot with economy and sales functionality. The original project lives in [V14 Slashlı Ekonomi + Satış Botu](./V14%20Slashl%C4%B1%20Ekonomi%20%2B%20Sat%C4%B1%C5%9F%20Botu).

- JavaScript · Node.js · discord.js v14
- Slash commands and event handlers
- Local database libraries for bot data

## Development

The original package specifies Node.js 16, which is end-of-life. Review dependencies and migrate to a supported runtime before deploying.

From the project directory:

```sh
npm install
npm start
```

Configure your own Discord application credentials locally before starting. Never commit bot tokens or secrets. Review the original configuration and license before reuse.
